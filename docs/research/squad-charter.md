## 2. Product Context (what we're researching for)

Tiktok Stream is a **no-code TikTok LIVE overlay builder ("Stream Studio")** built on `tiktok-live-api`. Creators connect their TikTok username and get live gift alerts, goal bars, leaderboards, mini-games (Marble Race, Gift War), PK predictions, and Avatar Arena — then publish via a browser-source URL.

- **Goal:** more viewers, then monetization (see IKI-28).
- **North star:** TikTok LIVE streamers (starting with Indonesia) adopt the overlay and keep their audience more engaged, longer.

## 4. Working Rules

1. **Evidence first** — every recommendation links to a concrete source (competitor page, review, comment, interview quote).
2. **Report back in the assigned ticket** — post the memo/plan in the ticket thread; summarize the top 3 findings + top 3 recommendations.
3. **Tie to product** — end every output with "so what for Stream Studio" (feature, flow, or messaging).
4. **No slop** — follow the anti-AI-slop content guide (see `docs/panduan-konten-anti-ai-slop.md`); use specific evidence, no empty superlatives.

## 5. Definition of Done

Each research ticket is done when: (a) the deliverable is posted in the ticket, (b) top findings + recommendations are summarized, and (c) it names at least one concrete product/monetization implication for Stream Studio.
